# 湖滨约会地图（v2）

发布地址：<https://kirrito-k423.github.io/hangzhou-rain-date/>

## 体验

全视口地图是主界面，详情默认隐藏。地图上的店铺标记可打开信息、加入/移出行程；路线段可点击打开距离、道路步骤和播放控制。行程列表支持调整顺序。预设为桌游、拼豆和轻逛，也可自由选点。URL hash保存站点、顺序、时间、晚饭及返程开关，兼容上一版分享链接。

“播放走法”逐个插值经过道路折线坐标，不使用两个地点之间的直线动画。相同商场内换层不绘制道路。晚饭尚未指定，只预留预算/时段，不生成地图点或虚构路径。

## 数据和坐标

- Leaflet 1.9.4，本地部署，附原始LICENSE；没有外部脚本/CDN依赖。
- `data/context.geojson`：2026-11-09从OpenStreetMap / Overpass API取得的500个道路、建筑、绿地和西湖湖岸要素。
- `data/anchors.json`：WGS-84。龙翔桥使用C口出入口点；商场内店铺使用其所在建筑的代表点，不宣称店内精确坐标。悦览树使用OSM地点节点。
- `data/walking-routes.json`：FOSSGIS OSRM **foot** 服务返回的30组定向步行路线及逐步信息，保留实际geometry与道路吸附点。路线缓存随页部署，不在运行时批量请求公共算路服务。
- 起终点的短灰虚线是建筑代表点与道路吸附点之间的示意接驳，未计入道路距离，不表示已验证的楼内通道。
- 道路距离/时间来自路线快照；停留时间、费用与进出店时间是规划估算。排队、购物、停车以及待定餐厅的实际转场未计。
- 步行路网不等于避雨路线。地下连通口和店内换层按现场导览走，商户营业及预约出发前确认。

默认简洁底图直接使用本页开放数据。可切换标准在线OSM底图，失败则恢复本地地图。遵守OSM瓦片政策，不预下载或提供离线瓦片。保留高德/百度查店与百度步行导航入口。

地图数据遵循[ODbL](https://www.openstreetmap.org/copyright)，页面持续显示贡献者及路线服务署名。FOSSGIS[使用政策](https://routing.openstreetmap.de/about.html)。源数据处理入口：`scripts/prepare_map_data.py`，请求按低于每秒一次顺序执行，并保留本地缓存。

# Map and routing data attribution

`context.geojson`, `anchors.json`, and `walking-routes.json` contain data derived from OpenStreetMap, © OpenStreetMap contributors, made available under the Open Database License (ODbL) 1.0.

- Copyright and licence: https://www.openstreetmap.org/copyright
- ODbL: https://opendatacommons.org/licenses/odbl/1-0/
- Source geometry: Overpass API, OpenStreetMap base timestamp recorded in context.geojson.
- Route geometry: FOSSGIS OSRM pedestrian (foot) routing, https://routing.openstreetmap.de/about.html
- Snapshot: 2026-11-09. Not a live navigation or opening-hours guarantee.

The source anchors and route geometry are provided in this directory for inspection and reuse under the applicable data licence. Route service attribution remains visible in the page footer.
